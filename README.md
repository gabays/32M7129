# Comment mieux faire? Ressources techniques complémentaires pour la recherche

- Simon Gabay
- Genève, semestre d'automne

## Programme

- `cours_01`: découvrir les outils
- `cours_02`: lignes de commande, bash, utiliser l'IA
- `cours_03`: découvrir eScriptorium
- `cours_04`: utiliser Kraken en ligne de commande
- `cours_05`: convertir les fichiers ALTO en XML-TEI
- `cours_06`: versionner son travail avec Git, GitHub (ou GitLab) et GitHub Desktop
